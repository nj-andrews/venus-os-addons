## Notes

* Some add-ons require specific hardware and are only useful with compatible devices.
* Setup steps and behavior can vary by Venus OS version.
* Prefer release feeds on production devices; use development feeds only for testing.
* The add-on docs can be used as both user-facing setup guides and developer-facing reference material.
